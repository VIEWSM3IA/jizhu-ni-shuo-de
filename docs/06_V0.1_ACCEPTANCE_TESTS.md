# V0.1 验收用例

## A. 创建

- [ ] 空 statement 不能提交
- [ ] 1 个可见字符不能提交；2 个可见字符可提交
- [ ] 80 字可提交，81 字被前端限制且服务端拒绝绕过请求
- [ ] alias 1–12 字规则前后端一致
- [ ] opens_at 小于服务端当前时间 +10 分钟被拒绝
- [ ] 超过 2 年被拒绝
- [ ] 创建成功后 Capsule 与 creator stance 在同一事务存在
- [ ] 创建后没有编辑入口
- [ ] 无人参与时发起人可撤销；有第 2 位参与者后不可撤销

## B. 分享进入

- [ ] 分享 path 只携带 capsule id，不携带 stance/alias 等敏感数据
- [ ] 冷启动直接打开详情，不依赖首页已有状态
- [ ] 失效 id 展示 INVALID，不无限 loading
- [ ] 分享标题过长能稳定截断

## C. 押话

- [ ] 未参与用户在截止前看到两个等权按钮
- [ ] 首次无 alias 时，点击 stance 后弹 alias Sheet
- [ ] alias 保存成功后自动继续原 stance，不需再选一次
- [ ] stance 成功后不能改
- [ ] 同一用户重复请求不会新增第二条
- [ ] 截止瞬间服务端拒绝迟到 stance
- [ ] SEALED 接口响应中不包含其他参与者 stance
- [ ] 截止前 UI 只显示总人数，不显示阵营人数

## D. 开封

- [ ] 到期前参与者无法开封，即使修改本机时间
- [ ] 到期后参与者可开封
- [ ] 到期后未参与者不可开封
- [ ] 两个参与者同时开封均得到一致 OPENED 状态
- [ ] OPENED 列表只返回给参与者
- [ ] 发起人置顶，其余按 submitted_at 排序稳定
- [ ] 不存在“赢家/输家/正确率”字段或 UI

## E. 首页

- [ ] 创建者能看到自己的 Capsule
- [ ] 参与者能看到参与的 Capsule
- [ ] DUE 优先展示
- [ ] 从详情开封后返回首页能刷新为 OPENED
- [ ] 空列表有完整空状态和创建 CTA

## F. 隐私与安全

- [ ] 任意业务 API 不返回 openid / unionid
- [ ] statement/alias 内容安全失败不落库
- [ ] 非参与者抓包也拿不到 opened results
- [ ] 仅前端隐藏不算通过，必须服务端字段级隔离
- [ ] Capsule ID 不使用可顺序枚举整数

## G. 弱网/错误

- [ ] 创建接口超时后重试不会产生两个 Capsule（推荐 client_request_id 或请求幂等键）
- [ ] stance 超时后重试不会重复写入
- [ ] open 超时后刷新能正确得到 OPENED
- [ ] skeleton / error / retry 无白屏
- [ ] CTA 请求中禁用，避免明显连点

## H. 真机视觉

至少验证：
- [ ] iPhone Dynamic Island 机型
- [ ] iPhone 非 Dynamic Island 机型
- [ ] Android 主流全面屏
- [ ] 微信深色模式下仍可读（V0.1 可固定浅色，但必须不被系统强制样式破坏）
- [ ] 键盘弹起后创建 CTA 可触达
- [ ] 系统右上角胶囊无重叠
