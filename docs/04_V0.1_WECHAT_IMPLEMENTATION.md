# V0.1 微信小程序实现说明

## 1. 技术形态

优先使用**原生微信小程序**（WXML/WXSS/JS/TS），避免为了两页产品引入重型跨端框架。

建议页面：

```text
pages/
  home/
    index
  capsule/
    detail
components/
  create-sheet/
  alias-sheet/
  capsule-card/
  sealed-status/
  opened-list/
  loading-skeleton/
services/
  api
  session
  analytics
utils/
  date
  text
  share
```

## 2. 导航

不使用 tabBar。

- 冷启动：`pages/home/index`
- 分享卡片：直接进入 `pages/capsule/detail?id=...`
- 详情返回：遵循微信页面栈；若由分享冷启动进入且无前页，提供页面内 `回首页` 入口

自定义 navigationStyle 可用，但必须：
- 根据状态栏和右上角菜单按钮动态留白
- 真机验证 iPhone Dynamic Island、普通刘海、Android
- 不覆盖微信系统胶囊

若自定义导航稳定性不足，优先退回原生导航栏，视觉趋势不能高于可用性。

## 3. 登录

启动时：
1. `wx.login()` 获取 code
2. `POST /auth/wechat` 换取服务端 session/token
3. 本地安全存储 token
4. 401 时只允许一次自动刷新/重新登录，避免循环

不依赖 `wx.getUserProfile` 获取真实头像昵称。

群内称呼：
- 用户主动输入
- 最近一次称呼可服务端保存并作为默认值返回
- Stance 必须保存 alias_snapshot

## 4. 分享

详情页实现 `onShareAppMessage`。

建议：

```js
onShareAppMessage() {
  const c = this.data.capsule;
  return {
    title: buildShareTitle(c.creator_alias, c.statement),
    path: `/pages/capsule/detail?id=${c.id}`,
    imageUrl: STATIC_SHARE_IMAGE
  };
}
```

注意：
- 业务状态不能依赖分享成功回调。
- 分享标题要做长度截断。
- 不在 V0.1 动态合成分享图。

## 5. Sheet 实现

Create/Alias 都作为当前页面内自定义组件，避免额外页面跳转。

要求：
- 遮罩点击可关闭，但字段已输入时需要二次确认或保留草稿
- 键盘弹出时 CTA 不得被遮挡
- 使用 `safe-area-inset-bottom`
- 支持 `catchtouchmove` 防止背景跟随滚动
- 动画只改变 transform/opacity，减少重排

## 6. 日期时间

客户端只负责选择和展示。

提交：ISO 8601 / epoch milliseconds。
服务端：统一 UTC 存储与判断是否截止。
客户端禁止通过修改本地时间提前开封。

## 7. 状态来源

详情接口直接返回面向当前用户的派生状态，客户端不要自己拼业务规则。

建议字段：

```json
{
  "state": "JOINABLE | SEALED | DUE | OPENED | INVALID",
  "viewer": {
    "is_creator": false,
    "is_participant": true,
    "my_stance": "agree"
  }
}
```

这样可以避免不同端状态判断漂移。

## 8. 页面生命周期

### Detail
- `onLoad`：读取 id，拉详情
- `onShow`：如果页面可能从分享/后台恢复且距离上次请求超过阈值，轻量刷新状态
- 到达 opens_at 后不要只靠前端 timer 自动切换；用户操作前再次请求服务端状态

### Home
- `onShow`：刷新列表，确保从 Detail 开封后首页状态同步
- 列表请求做 skeleton，不闪白屏

## 9. 内容与隐私

- statement / alias 服务端校验与内容安全
- API 永远不返回其他用户的 openid/unionid
- OPENED 名单只向参与者返回
- SEALED 状态不返回任何其他参与者 stance，即使前端“不展示”也不行；数据层就不能下发

## 10. 性能

V0.1 目标：
- 两个主包页面，无大图片依赖
- 首包尽量 < 1MB
- 分享图固定静态资源
- 首页 20 条分页
- 详情只返回必要数据
- 不引入 Lottie、图表库、富文本编辑器

## 11. 兼容降级

- blur/backdrop-filter 不可靠时使用高不透明背景 + 1px 半透明边框
- 动效失败不影响操作
- 订阅消息不属于 V0.1 主链路
- 所有 UI 先在 iOS 微信真机验证，再看 Android
