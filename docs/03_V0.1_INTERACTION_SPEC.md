# V0.1 交互规格

## 1. 设计基线

### 微信优先
- 保留微信右上角系统胶囊区域。
- 不自造“返回手势”替代微信页面栈。
- 分享使用标准小程序分享入口和按钮能力。
- 不出现独立 App 常见的 4–5 栏底部 TabBar。

### iOS 2026 视觉语言
- 内容层不透明、清晰。
- 浮层/导航层允许半透明和 blur；兼容不支持 blur 时回退到 92–96% 不透明背景。
- 控件呈圆润 capsule / rounded rectangle。
- 强调层级由字号、留白、材质和轻微缩放完成，不靠高饱和色块堆叠。

## 2. 首页

### 顶部
- 自定义导航安全区，高度基于 `wx.getWindowInfo()` 与菜单按钮位置动态计算。
- 大标题位于系统胶囊下方：`记住你说的`
- 次级说明可选：`把今天的话，留给以后。`

### Filter chips
`全部 / 进行中 / 待开封 / 已开封`

- 高度 34–36px
- 选中：深色文字 + 轻灰实底
- 未选：透明
- 横向滚动，不换行

### Capsule 卡片
卡片高度由内容决定，最小约 112px。

布局：
- 状态胶囊（小）
- statement 2 行
- 底部 metadata：`6 人押话 · 10/18 20:00 开封`

点击整卡进入详情。

### 创建 CTA
屏幕底部安全区上方的浮动 pill：
`＋ 记一句`

- 不占系统 TabBar
- 滚动时保持 fixed
- 背景接近黑色，文字白色
- 点击 scale 0.98，100ms；松开 spring 恢复

## 3. 创建 Sheet

### 进入
- 背景遮罩 20–28% 黑
- Sheet 从底部 220–280ms spring 上移
- 顶部圆角 32px
- 顶部 36px 拖拽柄仅视觉提示；V0.1 可不实现拖拽关闭

### 内容顺序
1. 标题：`记住这句话`
2. textarea 大号输入区，占视觉主体
3. 开封时间一行 + 快捷 chips
4. 群内称呼
5. 主 CTA
6. `创建后不可修改。`

### textarea
- placeholder：`比如：iPhone 19 还是不会有屏下摄像头`
- 字数计数靠右下
- 80 字上限
- 2 行起，高度自适应到 5 行后内部滚动

### 时间选择
快捷 chips：
- `今晚`
- `24 小时后`
- `7 天后`
- `自定义`

点击自定义打开微信原生 picker 或自定义日期时间 picker；生产实现优先稳定原生能力。

### 提交加载
- 按钮文案变 `正在锁住…`
- 禁止重复点击
- 成功后 Sheet 下沉，详情页进入
- 失败恢复按钮，并在按钮上方出现 1 行错误，不弹系统 alert 作为默认方案

## 4. JOINABLE 详情

### 首屏
视觉中心必须是原话，不是操作按钮。

结构：
- 小状态 `🔒 还在封存`
- 发起人：`AJ 把话放这了`
- statement 大标题
- 开封：`10 月 18 日 20:00`
- 分隔留白
- `已有 4 人押话`
- `截止前不显示任何人的选择`

底部固定双按钮：
`我同意` / `我反对`

两按钮视觉权重相同，避免默认暗示某一侧。

## 5. 群内称呼 Sheet

仅首次需要。

文案：
- 标题 `群里怎么叫你？`
- 说明 `开封时会用这个名字，不需要微信头像。`
- input type=text，1–12 字
- 主按钮 `就叫这个`

提交后立即继续用户刚才选择的 stance，不要求再次点击。

## 6. SEALED 详情

隐藏双按钮，底部呈现单一状态卡：

`✓ 你的选择已封存`
`你押了：同意`（只对本人显示）

下面可有一行轻提示：`到 10/18 20:00 前，其他人的选择不会公开。`

右上/底部提供标准分享按钮：`发给朋友押一句`

## 7. DUE 详情

首屏状态：
`⌛ 该开封了`

statement 保持原位置。

参与者可见：
- `当时共 4 人押话`
- 主按钮 `开封`

按钮点击：
- 轻触反馈
- 进入 420–600ms 的“封条松开”动画（纯 CSS/小程序动画，不需要视频/Lottie）
- 动画期间发 API
- API 成功后直接转 OPENED
- API 已被他人抢先开封也视为成功并加载 OPENED

## 8. OPENED 详情

标题：`那天大家是这么说的`

结果列表：
- 发起人第一行
- 其余按参与时间
- 左：alias_snapshot
- 右：`同意` / `反对`
- 同意、反对仅使用细微色彩区别，禁止“胜/负”图标

底部：
- `发回群里`
- 次级文本按钮：`再记一句`

## 9. Empty / Error

### INVALID
图标：打开的空锁（线性）
标题：`这句话已经不在了`
说明：`可能被发起人撤销，或者链接已经失效。`
按钮：`回到首页`

### 网络失败
保留原页面骨架，不清空到白屏。
按钮：`重试`

### 请求重复
所有 CTA 在请求中禁用；服务端仍必须幂等，前端禁用不能代替后端保护。

## 10. 文案规则

用“押话”而不是“下注”。
用“开封”而不是“开奖”。
用“同意 / 反对”而不是“YES / NO”。
用“当时大家怎么说”而不是“谁预测对了”。
