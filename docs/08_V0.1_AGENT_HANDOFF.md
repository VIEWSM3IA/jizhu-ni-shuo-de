# 交给开发 Agent 的 V0.1 执行说明

你要实现的是微信小程序「记住你说的」V0.1。仓库事实优先于本文；若仓库已有技术栈、lint、测试、部署规范，复用而不是另起体系。

## 产品边界

核心闭环只有：
`创建一句话 → 分享群 → 同意/反对 → 封存 → 到期 → 任一参与者开封 → 展示当时选择`

严禁擅自加入：排行、胜率、积分、虚拟币、内容流、评论、AI 判定结果、公开广场。

## 必须实现

1. 两页：Home、Capsule Detail
2. 两个组件 Sheet：Create、Alias
3. `wx.login` 服务端身份
4. 用户主动填写群内称呼，不依赖微信昵称头像
5. 创建即冻结；creator 自动 agree
6. 每个用户每个 Capsule 只能 stance 一次
7. 截止前服务端不下发其他人的 stance
8. 到期后仅参与者可 open / view results
9. open、stance、create 重试安全
10. 分享卡片 path 直达详情
11. 首页完整状态与刷新
12. 内容安全、鉴权、错误态、loading、弱网重试
13. 对照 `prototype/index.html` 实现视觉与交互，不把 HTML 直接嵌进小程序
14. 完成 `06_V0.1_ACCEPTANCE_TESTS.md` 全部可自动化部分

## UI 实现优先级

1. 微信真机可用性
2. 信息层级和手感
3. iOS 前沿材质感
4. 动效

玻璃效果不可导致文字对比度、性能或 Android 兼容问题。不可为了像 iOS 而破坏微信导航认知。

## 工程要求

- 业务状态由服务端 detail DTO 派生
- PostgreSQL 用唯一约束保护 stance
- 开封用条件 UPDATE/事务保证并发幂等
- 前端所有写操作有 loading lock
- API 错误码可枚举，不解析中文错误文案做逻辑
- 关键流程写 E2E 或集成测试
- 在 iOS/Android 微信真机验收

## 完成定义

当且仅当：
- 所有 P0/P1 验收通过
- 无 privacy leak
- 并发开封/重复 stance 测试通过
- 分享冷启动可用
- 原型关键交互均落地
- README 中提供本地启动、测试、构建、体验版发布步骤

才可标记 V0.1 Frozen。
