# 最终产品形态大纲

## 1. 产品定义

**产品名（工作名）**：记住你说的

**一句话**：朋友群里有人放话时，把这句话锁死；事情发生以后回来开封。

**核心价值**：不是预测“未来会怎样”，而是保存“当时大家怎么说”。

**核心情绪**：`行，你今天说的，我给你记下来了。`

## 2. 最终闭环

群聊出现一句值得记住的话 → 10 秒创建 → 分享小程序卡片到群 → 朋友各自押「同意 / 反对」 → 截止前全部封存 → 到期任一参与者开封 → 展示当初每个人的选择 → 回群讨论。

产品终局仍然保持这一条闭环，不通过“加功能”改变产品类别。

## 3. 最终信息架构

### 首页

只解决两件事：

- 找回我创建/参与过的记录
- 创建一条新的“话”

列表按状态组织：

- 进行中
- 待开封
- 已开封

不做内容流、推荐流、陌生人广场。

### 详情页

单一页面承载全部生命周期：

- `JOINABLE`：未参与且未截止，可押话
- `SEALED`：已参与且未截止，只展示“你的选择已封存”
- `DUE`：已截止未开封，参与者可点击开封
- `OPENED`：展示所有参与者在当时的选择
- `INVALID`：已撤销/不存在/不可访问

### Sheet

- 创建 Sheet
- 首次参与时的群内称呼 Sheet
- 后续版本可增加“到期提醒”授权 Sheet，但不新增独立页面

## 4. 核心产品规则

1. **创建即冻结**：一句话和开封时间创建后不可编辑。写错只能在无人参与时撤销后重建。
2. **发起人默认同意**：创建即生成发起人的 stance=true。
3. **每人只能押一次**：提交后不可修改，保持“当时说了什么”的可信感。
4. **截止前不显示结果**：不显示谁选了什么，也不显示同意/反对人数分布；只显示总参与人数。
5. **到期不自动判输赢**：系统只负责开封原始选择，不负责裁判事实。
6. **任何参与者可开封**：避免依赖发起人回访。
7. **无社交资产化**：没有胜率、等级、排行榜、积分、连续签到、虚拟币。
8. **无陌生人关系链**：V1 前不做广场、关注、私信、好友榜。
9. **不强取微信昵称/头像**：身份展示使用用户主动填写的“群内称呼”快照。
10. **链接私密而非群绑定**：V0.x 不依赖群 ID；拥有小程序卡片/链接的人可进入，但开封结果默认仅参与者可见。

## 5. 最终对象模型

### Capsule（话题胶囊）

- 一句话 statement
- 发起人 creator
- 开封时间 opens_at
- 状态 sealed / opened / cancelled
- 创建时间

### Stance（押话）

- capsule_id
- user_id
- alias_snapshot
- stance: agree / disagree
- submitted_at

### User（最小用户）

- 微信身份映射（openid/unionid，服务端）
- 最近使用的群内称呼
- 不强制头像

## 6. 最终体验语言

产品中的关键词统一使用：

- 创建：**记一句** / **锁住这句话**
- 参与：**我同意** / **我反对**
- 已参与：**你的选择已封存**
- 到期：**该开封了**
- 揭晓：**开封**
- 已揭晓：**那天大家是这么说的**

避免：竞猜、下注、投注、赔率、输赢、战绩、预测准确率。

## 7. 最终视觉语言

### 设计目标

“像一个长在微信里的 2026 iOS 轻工具”，而不是复制 iOS App，也不是传统微信工具小程序。

### 视觉规则

- 背景：接近系统 grouped background 的冷白灰，不用暖灰纸张感。
- 主内容卡：纯色或极轻透明，重点是排版和留白。
- 玻璃材质：只用于顶部导航、底部关键操作、Sheet 浮层；禁止所有卡片都毛玻璃。
- 圆角：卡片 22–28px，按钮 16–22px，Sheet 顶部 30–34px。
- 字体：系统字体；一句话正文 26–32px，强调“说过的话”本身。
- 色彩：默认黑白灰；同意用低饱和蓝/绿倾向色，反对用低饱和红/橙倾向色，但结果揭晓前不使用左右阵营色强化群体影响。
- 动效：100–260ms，小范围 spring / fade / scale；不做炫技转场。
- 无底部 TabBar，主要 CTA 靠近拇指区。

## 8. 永久不做清单

以下能力除非产品定位被明确推翻，否则不进入 Roadmap：

- 预测市场 / 金钱下注
- 虚拟币 / 积分经济
- 胜率、命中率、战绩榜
- 公共预测 Feed
- 连续签到
- AI 判断输赢
- 自动爬取新闻判定结果
- 复杂社交关系链
- 重型个人主页

## 9. 最终成功标准

产品是否成立，不看 DAU，而看以下行为是否自然发生：

- 用户能在群聊语境下快速创建
- 群友看到卡片后愿意押一次话
- 截止前不会因为结果可见而互相影响
- 到期后有人愿意开封
- 开封结果会被重新带回群聊

核心指标：**到期开封率**。
